## Paper I

### Question 1

**(a) [10 marks]**

Find one vector in R^{3} which generates the intersection of V and W, where V is the xy plane and W is the space generated by the vectors (1, 2, 3) and (1, −1, 1).

**(b) [10 marks]**

Using elementary row or column operations, find the rank of the matrix [[0, 1, −3, −1], [0, 0, 1, 1], [3, 1, 0, 2], [1, 1, −2, 0]].

**(c) [10 marks]**

Prove that between two real roots of e^{x} cos x + 1 = 0, a real root of e^{x} sin x + 1 = 0 lies.

**(d) [10 marks]**

Evaluate: ∫_{0}^{1} [log_{e}(1 + x)/(1 + x^{2})] dx

**(e) [10 marks]**

Examine whether the plane x + y + z = 0 cuts the cone yz + zx + xy = 0 in perpendicular lines.

### Question 2

**(a) [15 marks]**

Let V and W be the following subspaces of R^{4}:
V = {(a, b, c, d) : b − 2c + d = 0} and
W = {(a, b, c, d) : a = d, b = 2c}.
Find a basis and the dimension of (i) V, (ii) W, (iii) V ∩ W.

**(b) [20 marks]**

(i) Investigate the values of λ and μ so that the equations x + y + z = 6, x + 2y + 3z = 10, x + 2y + λz = μ have (1) no solution, (2) a unique solution, (3) an infinite number of solutions. (10)
(ii) Verify Cayley-Hamilton theorem for the matrix A = [[1, 4], [2, 3]] and hence find its inverse. Also, find the matrix represented by A^{5} − 4A^{4} − 7A^{3} + 11A^{2} − A − 10I. (10)

**(c) [15 marks]**

By using the transformation x + y = u, y = uv, evaluate the integral ∬ {xy(1 − x − y)}^{1/2} dx dy taken over the area enclosed by the straight lines x = 0, y = 0 and x + y = 1.

### Question 3

**(a) [15 marks]**

Find the height of the cylinder of maximum volume that can be inscribed in a sphere of radius a.

**(b) [20 marks]**

Find the maximum or minimum values of x^{2} + y^{2} + z^{2} subject to the conditions ax^{2} + by^{2} + cz^{2} = 1 and *l*x + my + nz = 0. Interpret the result geometrically.

**(c) [15 marks]**

(i) Let A = [[−2, 2, −3], [2, 1, −6], [−1, −2, 0]]. Find the eigen values of A and the corresponding eigen vectors. (8)
(ii) Prove that the eigen values of a unitary matrix have absolute value 1. (7)

### Question 4

**(a) [20 marks]**

(i) Find the co-ordinates of the points on the sphere x^{2} + y^{2} + z^{2} − 4x + 2y = 4, the tangent planes at which are parallel to the plane 2x − y + 2z = 1. (10)
(ii) Prove that the equation ax^{2} + by^{2} + cz^{2} + 2ux + 2vy + 2wz + d = 0 represents a cone if u^{2}/a + v^{2}/b + w^{2}/c = d. (10)

**(b) [15 marks]**

Show that the lines drawn from the origin parallel to the normals to the central conicoid ax^{2} + by^{2} + cz^{2} = 1, at its points of intersection with the plane *l*x + my + nz = p generate the cone p^{2}(x^{2}/a + y^{2}/b + z^{2}/c) = (*l*x/a + my/b + nz/c)^{2}.

**(c) [15 marks]**

Find the equations of the two generating lines through any point (a cos θ, b sin θ, 0), of the principal elliptic section x^{2}/a^{2} + y^{2}/b^{2} = 1, z = 0, of the hyperboloid by the plane z = 0.

### Question 5

**(a) [10 marks]**

Justify that a differential equation of the form [y + x f(x^{2} + y^{2})] dx + [y f(x^{2} + y^{2}) − x] dy = 0, where f(x^{2} + y^{2}) is an arbitrary function of (x^{2} + y^{2}), is not an exact differential equation and 1/(x^{2} + y^{2}) is an integrating factor for it. Hence solve this differential equation for f(x^{2} + y^{2}) = (x^{2} + y^{2})^{2}.

**(b) [10 marks]**

Find the curve for which the part of the tangent cut-off by the axes is bisected at the point of tangency.

**(c) [10 marks]**

A particle is performing a simple harmonic motion (S.H.M.) of period T about a centre O with amplitude a and it passes through a point P, where OP = b in the direction OP. Prove that the time which elapses before it returns to P is (T/π) cos^{−1}(b/a).

**(d) [10 marks]**

Two equal uniform rods AB and AC, each of length *l*, are freely jointed at A and rest on a smooth fixed vertical circle of radius r. If 2θ is the angle between the rods, then find the relation between *l*, r and θ, by using the principle of virtual work.

**(e) [10 marks]**

Find the curvature vector at any point of the curve r̄(t) = t cos t î + t sin t ĵ, 0 ≤ t ≤ 2π. Give its magnitude also.

### Question 6

**(a) [10 marks]**

Solve by the method of variation of parameters: dy/dx − 5y = sin x

**(b) [20 marks]**

Solve the differential equation: x^{3} d^{3}y/dx^{3} + 3x^{2} d^{2}y/dx^{2} + x dy/dx + 8y = 65 cos(log_{e} x)

**(c) [20 marks]**

Evaluate by Stokes' theorem ∫_{Γ} (y dx + z dy + x dz) where Γ is the curve given by x^{2} + y^{2} + z^{2} − 2ax − 2ay = 0, x + y = 2a, starting from (2a, 0, 0) and then going below the z-plane.

### Question 7

**(a) [15 marks]**

Solve the following differential equation: x d^{2}y/dx^{2} − 2(x + 1) dy/dx + (x + 2)y = (x − 2)e^{2x}, when e^{x} is a solution to its corresponding homogeneous differential equation.

**(b) [15 marks]**

A particle of mass m, hanging vertically from a fixed point by a light inextensible cord of length *l*, is struck by a horizontal blow which imparts to it a velocity 2√(g*l*). Find the velocity and height of the particle from the level of its initial position when the cord becomes slack.

**(c) [20 marks]**

A regular pentagon ABCDE, formed of equal heavy uniform bars jointed together, is suspended from the joint A, and is maintained in form by a light rod joining the middle points of BC and DE. Find the stress in this rod.

### Question 8

**(a) [15 marks]**

Find the sufficient condition for the differential equation M(x, y) dx + N(x, y) dy = 0 to have an integrating factor as a function of (x + y). What will be the integrating factor in that case? Hence find the integrating factor for the differential equation (x^{2} + xy) dx + (y^{2} + xy) dy = 0, and solve it.

**(b) [15 marks]**

A particle is acted on by a force parallel to the axis of y whose acceleration (always towards the axis of x) is μy^{−2} and when y = a, it is projected parallel to the axis of x with velocity √(2μ/a). Find the parametric equation of the path of the particle. Here μ is a constant.

**(c) [20 marks]**

Solve the initial value problem d^{2}y/dt^{2} + y = 8e^{−2t} sin t, y(0) = 0, y′(0) = 0 by using Laplace-transform.

## Paper II

### Question 1

**(a) [10 marks]**

Let G be the set of all real 2 × 2 matrices [[x, y], [0, z]], where xz ≠ 0. Show that G is a group under matrix multiplication. Let N denote the subset {[[1, a], [0, 1]] : a ∈ ℝ}. Is N a normal subgroup of G? Justify your answer.

**(b) [10 marks]**

Test the convergence of the improper integral ∫_{1}^{∞} dx/[x^{2}(1 + e^{−x})].

**(c) [10 marks]**

Prove that the function f(z) = u + iv, where f(z) = [x^{3}(1 + i) − y^{3}(1 − i)]/(x^{2} + y^{2}), z ≠ 0; f(0) = 0 satisfies Cauchy-Riemann equations at the origin, but the derivative of f at z = 0 does not exist.

**(d) [10 marks]**

Expand in Laurent series the function f(z) = 1/[z^{2}(z − 1)] about z = 0 and z = 1.

**(e) [10 marks]**

Solve graphically:
Maximize Z = 6x_{1} + 5x_{2}
subject to
2x_{1} + x_{2} ≤ 16
x_{1} + x_{2} ≤ 11
x_{1} + 2x_{2} ≥ 6
5x_{1} + 6x_{2} ≤ 90
x_{1}, x_{2} ≥ 0

### Question 2

**(a) [15 marks]**

Show that ℤ_{7} is a field. Then find ([5] + [6])^{−1} and (−[4])^{−1} in ℤ_{7}.

**(b) [15 marks]**

Integrate ∫_{0}^{1} f(x) dx, where
f(x) = 2x sin(1/x) − cos(1/x), x ∈ ]0, 1]
f(x) = 0, x = 0

**(c) [20 marks]**

Find the initial basic feasible solution to the following transportation problem by Vogel's approximation method. Also, find its optimal solution and the minimum transportation cost:

| Origin | D_{1} | D_{2} | D_{3} | D_{4} | Supply |
|---|---|---|---|---|---|
| O_{1} | 6 | 4 | 1 | 5 | 14 |
| O_{2} | 8 | 9 | 2 | 7 | 16 |
| O_{3} | 4 | 3 | 6 | 2 | 5 |
| Demand | 6 | 10 | 15 | 4 | |

### Question 3

**(a) [15 marks]**

Show that the set {a + bω : ω^{3} = 1}, where a and b are real numbers, is a field with respect to usual addition and multiplication.

**(b) [15 marks]**

Obtain ∂^{2}f(0, 0)/∂x∂y and ∂^{2}f(0, 0)/∂y∂x for the function
f(x, y) = xy(3x^{2} − 2y^{2})/(x^{2} + y^{2}), (x, y) ≠ (0, 0)
f(x, y) = 0, (x, y) = (0, 0).
Also, discuss the continuity of ∂^{2}f/∂x∂y and ∂^{2}f/∂y∂x at (0, 0).

**(c) [20 marks]**

Evaluate the integral ∫_{0}^{π} dθ/(1 + (1/2) cos θ)^{2} using residues.

### Question 4

**(a) [15 marks]**

Prove that the set ℚ(√5) = {a + b√5 : a, b ∈ ℚ} is a commutative ring with identity.

**(b) [15 marks]**

Find the minimum value of x^{2} + y^{2} + z^{2} subject to the condition xyz = a^{3} by the method of Lagrange multipliers.

**(c) [20 marks]**

Find all optimal solutions of the following linear programming problem by the simplex method:
Maximize Z = 30x_{1} + 24x_{2}
subject to
5x_{1} + 4x_{2} ≤ 200
x_{1} ≤ 32
x_{2} ≤ 40
x_{1}, x_{2} ≥ 0

### Question 5

**(a) [10 marks]**

Solve the partial differential equation (2D^{2} − 5DD′ + 2D′^{2})z = 24(y − x).

**(b) [10 marks]**

Apply Newton-Raphson method to determine a root of the equation cos x − xe^{x} = 0 correct up to four decimal places.

**(c) [10 marks]**

Use five subintervals to integrate ∫_{0}^{1} dx/(1 + x^{2}) using trapezoidal rule.

**(d) [10 marks]**

Use only AND and OR logic gates to construct a logic circuit for the Boolean expression z = xy + uv.

**(e) [10 marks]**

Find the equation of motion of a compound pendulum using Hamilton's equations.

### Question 6

**(a) [15 marks]**

Reduce the equation ∂^{2}z/∂x^{2} = x^{2} ∂^{2}z/∂y^{2} to canonical form.

**(b) [15 marks]**

Solve the system of equations
2x_{1} − x_{2} = 7
−x_{1} + 2x_{2} − x_{3} = 1
−x_{2} + 2x_{3} = 1
using Gauss-Seidel iteration method (Perform three iterations).

**(c) [20 marks]**

Use Runge-Kutta formula of fourth order to find the value of y at x = 0.8, where dy/dx = √(x + y), y(0.4) = 0.41. Take the step length h = 0.2.

### Question 7

**(a) [15 marks]**

Find the deflection of a vibrating string (length = π, ends fixed, ∂^{2}u/∂t^{2} = ∂^{2}u/∂x^{2}) corresponding to zero initial velocity and initial deflection f(x) = k(sin x − sin 2x).

**(b) [15 marks]**

Draw a flowchart for Simpson's one-third rule.

**(c) [20 marks]**

Given the velocity potential φ = (1/2) log[((x + a)^{2} + y^{2})/((x − a)^{2} + y^{2})], determine the streamlines.

### Question 8

**(a) [15 marks]**

Solve ∂^{2}u/∂t^{2} = ∂^{2}u/∂x^{2}, 0 < x < 1, t > 0, given that
(i) u(x, 0) = 0, 0 ≤ x ≤ 1
(ii) ∂u/∂t (x, 0) = x^{2}, 0 ≤ x ≤ 1
(iii) u(0, t) = u(1, t) = 0, for all t

**(b) [15 marks]**

For any Boolean variables x and y, show that x + xy = x.

**(c) [20 marks]**

Find Navier-Stokes equation for a steady laminar flow of a viscous incompressible fluid between two infinite parallel plates.

## Paper I

### Question 1

**(a) [10 marks]**

The vectors V_{1} = (1, 1, 2, 4), V_{2} = (2, −1, −5, 2), V_{3} = (1, −1, −4, 0) and V_{4} = (2, 1, 1, 6) are linearly independent. Is it true? Justify your answer.

**(b) [10 marks]**

Reduce the following matrix to row echelon form and hence find its rank: [[1, 2, 3, 4], [2, 1, 4, 5], [1, 5, 5, 7], [8, 1, 14, 17]].

**(c) [10 marks]**

Evaluate the following limit: lim_{x→a} (2 − x/a)^{tan(πx/2a)}.

**(d) [10 marks]**

Evaluate the following integral: ∫_{π/6}^{π/3} [∛(sin x)/(∛(sin x) + ∛(cos x))] dx.

**(e) [10 marks]**

For what positive value of a, the plane ax − 2y + z + 12 = 0 touches the sphere x^{2} + y^{2} + z^{2} − 2x − 4y + 2z − 3 = 0 and hence find the point of contact.

### Question 2

**(a) [12 marks]**

If matrix A = [[1, 0, 0], [1, 0, 1], [0, 1, 0]] then find A^{30}.

**(b) [13 marks]**

A conical tent is of given capacity. For the least amount of Canvas required, for it, find the ratio of its height to the radius of its base.

**(c) [12 marks]**

Find the eigen values and eigen vectors of the matrix: [[1, 1, 3], [1, 5, 1], [3, 1, 1]].

**(d) [13 marks]**

If 6x = 3y = 2z represents one of the three mutually perpendicular generators of the cone 5yz − 8zx − 3xy = 0 then obtain the equations of the other two generators.

### Question 3

**(a) [12 marks]**

Let V = ℝ^{3} and T ∈ A(V), for all a_{i} ∈ A(V), be defined by T(a_{1}, a_{2}, a_{3}) = (2a_{1} + 5a_{2} + a_{3}, −3a_{1} + a_{2} − a_{3}, −a_{1} + 2a_{2} + 3a_{3}). What is the matrix T relative to the basis V_{1} = (1, 0, 1), V_{2} = (−1, 2, 1), V_{3} = (3, −1, 1)?

**(b) [13 marks]**

Which point of the sphere x^{2} + y^{2} + z^{2} = 1 is at the maximum distance from the point (2, 1, 3)?

**(c) [13 marks]**

(i) Obtain the equation of the plane passing through the points (2, 3, 1) and (4, −5, 3) parallel to x-axis. (6)
(ii) Verify if the lines (x − a + d)/(α − δ) = (y − a)/α = (z − a − d)/(α + δ) and (x − b + c)/(β − γ) = (y − b)/β = (z − b − c)/(β + γ) are coplanar. If yes, then find the equation of the plane in which they lie. (7)

**(d) [12 marks]**

Evaluate the integral ∬_{R} (x − y)^{2} cos^{2}(x + y) dx dy where R is the rhombus with successive vertices as (π, 0), (2π, π), (π, 2π), (0, π).

### Question 4

**(a) [13 marks]**

Evaluate ∬_{R} √|y − x^{2}| dx dy where R = [−1, 1 ; 0, 2].

**(b) [12 marks]**

Find the dimension of the subspace of ℝ^{4}, spanned by the set {(1, 0, 0, 0), (0, 1, 0, 0), (1, 2, 0, 1), (0, 0, 0, 1)}. Hence find its basis.

**(c) [13 marks]**

Two perpendicular tangent planes to the paraboloid x^{2} + y^{2} = 2z intersect in a straight line in the plane x = 0. Obtain the curve to which this straight line touches.

**(d) [12 marks]**

For the function f(x, y) = (x^{2} − x√y)/(x^{2} + y), (x, y) ≠ (0, 0); f(x, y) = 0, (x, y) = (0, 0), examine the continuity and differentiability.

### Question 5

**(a) [10 marks]**

Solve the differential equation: x cos x dy/dx + y(x sin x + cos x) = 1.

**(b) [10 marks]**

Solve the differential equation: (2xy^{4}e^{y} + 2xy^{3} + y)dx + (x^{2}y^{4}e^{y} − x^{2}y^{2} − 3x)dy = 0.

**(c) [10 marks]**

A body moving under SHM has an amplitude 'a' and time period 'T'. If the velocity is trebled, when the distance from mean position is (2/3)a, the period being unaltered, find the new amplitude.

**(d) [10 marks]**

A rod of 8 kg is movable in a vertical plane about a hinge at one end, another end is fastened a weight equal to half of the rod, this end is fastened by a string of length *l* to a point at a height b above the hinge vertically. Obtain the tension in the string.

**(e) [10 marks]**

Find the angle between the surfaces x^{2} + y^{2} + z^{2} − 9 = 0 and z = x^{2} + y^{2} − 3 at (2, −1, 2).

### Question 6

**(a) [12 marks]**

Find the constant a so that (x + y)^{a} is the Integrating factor of (4x^{2} + 2xy + 6y)dx + (2x^{2} + 9y + 3x)dy = 0 and hence solve the differential equation.

**(b) [13 marks]**

Two equal ladders of weight 4 kg each are placed so as to lean at A against each other with their ends resting on a rough floor, given the coefficient of friction is μ. The ladders at A make an angle 60° with each other. Find what weight on the top would cause them to slip.

**(c) [12 marks]**

Find the value of λ and μ so that the surfaces λx^{2} − μyz = (λ + 2)x and 4x^{2}y + z^{3} = 4 may intersect orthogonally at (1, −1, 2).

**(d) [13 marks]**

A mass starts from rest at a distance 'a' from the centre of force which attracts inversely as the distance. Find the time of arriving at the centre.

### Question 7

**(a) [12 marks]**

(i) Obtain Laplace Inverse transform of {ln(1 + 1/s^{2}) + [s/(s^{2} + 25)] e^{−πs}}.
(ii) Using Laplace transform, solve y″ + y = t, y(0) = 1, y′(0) = −2. (6 + 6 = 12)

**(b) [13 marks]**

A particle is projected from the base of a hill whose slope is that of a right circular cone, whose axis is vertical. The projectile grazes the vertex and strikes the hill again at a point on the base. If the semivertical angle of the cone is 30°, h is height, determine the initial velocity u of the projection and its angle of projection.

**(c) [12 marks]**

A vector field is given by F̄ = (x^{2} + xy^{2})î + (y^{2} + x^{2}y)ĵ. Verify that the field F̄ is irrotational or not. Find the scalar potential.

**(d) [13 marks]**

Solve the differential equation x = py − p^{2} where p = dy/dx.

### Question 8

**(a) [12 marks]**

Find the length of an endless chain which will hang over a circular pulley of radius 'a' so as to be in contact with the two-thirds of the circumference of the pulley.

**(b) [13 marks]**

A particle moves in a plane under a force, towards a fixed centre, proportional to the distance. If the path of the particle has two apsidal distances a, b (a > b), then find the equation of the path.

**(c) [12 marks]**

Evaluate ∫_{C} e^{−x}(sin y dx + cos y dy), where C is the rectangle with vertices (0, 0), (π, 0), (π, π/2), (0, π/2).

**(d) [13 marks]**

Solve: x^{4} d^{4}y/dx^{4} + 6x^{3} d^{3}y/dx^{3} + 4x^{2} d^{2}y/dx^{2} − 2x dy/dx − 4y = x^{2} + 2 cos(log_{e} x).

## Paper II

### Question 1

**(a) [10 marks]**

(i) How many generators are there of the cyclic group G of order 8? Explain.
(ii) Taking a group {e, a, b, c} of order 4, where e is the identity, construct composition tables showing that one is cyclic while the other is not. (5 + 5 = 10)

**(b) [10 marks]**

Give an example of a ring having identity but a subring of this having a different identity.

**(c) [10 marks]**

Test the convergence and absolute convergence of the series ∑_{n=1}^{∞} (−1)^{n+1} n/(n^{2} + 1).

**(d) [10 marks]**

Show that the function v(x, y) = ln(x^{2} + y^{2}) + x + y is harmonic. Find its conjugate harmonic function u(x, y). Also, find the corresponding analytic function f(z) = u + iv in terms of z.

**(e) [10 marks]**

Solve the following assignment problem to *maximize* the sales:

| Salesman | I | II | III | IV | V |
|---|---|---|---|---|---|
| A | 3 | 4 | 5 | 6 | 7 |
| B | 4 | 15 | 13 | 7 | 6 |
| C | 6 | 13 | 12 | 5 | 11 |
| D | 7 | 12 | 15 | 8 | 5 |
| E | 8 | 13 | 10 | 6 | 9 |

### Question 2

**(a) [15 marks]**

If R is a ring with unit element 1 and φ is a homomorphism of R onto R′, prove that φ(1) is the unit element of R′.

**(b) [15 marks]**

Is the function
f(x) = 1/n, 1/(n + 1) < x ≤ 1/n
f(x) = 0, x = 0
Riemann integrable? If yes, obtain the value of ∫_{0}^{1} f(x) dx.

**(c) [20 marks]**

Find all possible Taylor's and Laurent's series expansions of the function f(z) = (2z − 3)/(z^{2} − 3z + 2) about the point z = 0.

### Question 3

**(a) [15 marks]**

State Cauchy's residue theorem. Using it, evaluate the integral ∫_{C} (e^{z} + 1)/[z(z + 1)(z − i)^{2}] dz; C : |z| = 2.

**(b) [15 marks]**

Test the series of functions ∑_{n=1}^{∞} nx/(1 + n^{2}x^{2}) for uniform convergence.

**(c) [20 marks]**

Consider the following linear programming problem:
Maximize Z = x_{1} + 2x_{2} − 3x_{3} + 4x_{4}
subject to
x_{1} + x_{2} + 2x_{3} + 3x_{4} = 12
x_{2} + 2x_{3} + x_{4} = 8
x_{1}, x_{2}, x_{3}, x_{4} ≥ 0
(i) Using the definition, find its all *basic solutions*. Which of these are degenerate basic feasible solutions and which are non-degenerate basic feasible solutions?
(ii) Without solving the problem, show that it has an optimal solution. Which of the basic feasible solution(s) is/are optimal?

### Question 4

**(a) [15 marks]**

Do the following sets form integral domains with respect to ordinary addition and multiplication? If so, state if they are fields:
(i) The set of numbers of the form b√2 with b rational
(ii) The set of even integers
(iii) The set of positive integers (5 + 6 + 4 = 15)

**(b) [15 marks]**

Find the *absolute* maximum and minimum values of the function f(x, y) = x^{2} + 3y^{2} − y over the region x^{2} + 2y^{2} ≤ 1.

**(c) [20 marks]**

Solve the following linear programming problem by the simplex method. Write its dual. Also, write the optimal solution of the dual from the optimal table of the given problem:
Maximize Z = 2x_{1} − 4x_{2} + 5x_{3}
subject to
x_{1} + 4x_{2} − 2x_{3} ≤ 2
−x_{1} + 2x_{2} + 3x_{3} ≤ 1
x_{1}, x_{2}, x_{3} ≥ 0

### Question 5

**(a) [10 marks]**

Solve the partial differential equation (y^{2} + z^{2} − x^{2})p − 2xyq + 2xz = 0 where p = ∂z/∂x and q = ∂z/∂y.

**(b) [10 marks]**

Solve (D^{2} + DD′ − 2D′^{2})u = e^{x+y}, where D = ∂/∂x and D′ = ∂/∂y.

**(c) [10 marks]**

Find the principal (or canonical) disjunctive normal form in three variables p, q, r for the Boolean expression ((p ∧ q) → r) ∨ ((p ∧ q) → ¬r). Is the given Boolean expression a contradiction or a tautology?

**(d) [10 marks]**

Consider a uniform flow U_{0} in the positive x-direction. A cylinder of radius a is located at the origin. Find the stream function and the velocity potential. Find also the stagnation points.

**(e) [10 marks]**

Calculate the moment of inertia of a solid uniform hemisphere x^{2} + y^{2} + z^{2} = a^{2}, z ≥ 0 with mass m about the OZ-axis.

### Question 6

**(b) [15 marks]**

Solve the plane pendulum problem using the Hamiltonian approach and show that H is a constant of motion.

**(c) [20 marks]**

### Question 8

# Assessment Planning Status

Updated 26 November 2026. [Mains test generation](MAINS-TEST-GENERATION.md) and [Mains evaluation](MAINS-ANSWER-EVALUATION.md) now cover GS I–IV, Essay, Hindi A, English B and Mathematics I–II. Separate Essay and language method files are no longer proposed. This file records remaining planning, not another executable method.

- Verify the selected paper's latest section allocations, choice rules and instructions before full-paper generation. Language PYQ files remain extraction placeholders; use verified papers and the source limitations in their curricula.
- Teaching readiness remains separate from method availability. Chapter/cumulative tests require substantive content; early full-paper tests may be diagnostic.
- Prelims cumulative/full-length CSAT methods and dedicated MCQ checkpoint methods remain to be specified.
- Detailed revision scheduling and retention modelling remain open in [SPECIFICATION.md](SPECIFICATION.md). Optional standalone language drills can be designed later if requested; they are not required by the existing modes.

No tests, evaluator guides or attempts are created by this update. Interview preparation and other optional subjects remain outside scope.

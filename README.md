# UPSC CSE 2027 — Complete Preparation Guide

Complete preparation guide for the UPSC Civil Services Examination 2027, written for a complete beginner with no prior UPSC preparation, coaching, or subject background. Covers every paper of both Prelims and Mains, with the Mathematics optional (Papers VI and VII) included as the selected optional subject.

## Conventions

Each paper folder contains:

- `<paper-name>-Syllabus.md` — the official UPSC syllabus, verbatim
- `<paper-name>-Curriculum.md` — a comprehensive, phased curriculum, generated from the researched exam pattern, the syllabus, and PYQs; doubles as the index
- `<paper-name>-PYQS/<year>-<paper-name>.md` — year-wise PYQ notes (2013–2026), one file per exam year; for two-paper subjects, both papers appear in separate Paper I and Paper II sections
- `<chapter>.md` or `<chapter>-part-N.md` — chapter content; split parts only when a curriculum chapter is too large, with every part linked from the curriculum
- `Prelims-<paper>-TESTS/<test-id>.md` — on-demand chapter-part practice tests for Prelims; feedback is appended in the same file
- `Mains-<paper>-TESTS/<test-id>.md` — on-demand Mains GS I–IV tests; evaluation is appended in the same file (GS I–IV only)

## Status

Root [syllabus.md](syllabus.md) contains the complete official syllabus, and all per-paper syllabus files are populated verbatim. The Mathematics optional syllabus is copied verbatim from the official notification because root [syllabus.md](syllabus.md) does not reproduce detailed optional syllabi.

Across all papers, 140 PYQ files exist for 2013–2026: 111 are populated and 29 are placeholders. Year-wise PYQ files are populated for the Mains Essay and GS I–IV papers, Prelims General Studies I, and the Mathematics optional Papers I and II. The Mathematics optional PYQ folder is populated for 2013–2026 from typed transcriptions; 2013 was reconstructed from a secondary transcription and is marked for verification against the linked question-paper copies. Prelims CSAT is populated for 2014–2026 from a typed compilation with source gaps flagged in the affected files. Prelims CSAT 2013 and the two language-paper PYQ sets (Hindi Paper A, English Paper B) await extraction from official scanned papers and account for all 29 placeholders. Hindi is the selected compulsory Indian language. Each populated file records its source URL, access date, question count, and a source caveat.

The [Prelims General Studies I curriculum](Prelims-General-Studies-I/Prelims-General-Studies-I-Curriculum.md) is populated with 136 planned chapters numbered consecutively from 001 to 136 across 10 phases, from exam orientation and beginner foundations to subject coverage, PYQ application and revision. Chapters [009](Prelims-General-Studies-I/009-weathering-erosion-and-landforms.md) and [012](Prelims-General-Studies-I/012-world-climates-and-the-indian-monsoon.md) are authored; every other chapter file is still a marked planning placeholder whose teaching content has not yet been authored.

The [Mathematics optional curriculum](Mains-Mathematics/Mains-Mathematics-Curriculum.md), prepared on 15 November 2026, covers both papers through 80 planned chapters numbered 001–080 across 13 phases. It provides diagnostic-guided foundation routing for a returning Physics graduate, a rigorous theory-first sequence, a four-hour daily study routine, syllabus mapping, prerequisites, PYQ references and optional resources. Chapter 001 (orientation and diagnostic route) is authored; the other 79 Mathematics chapter files exist as planning placeholders, and diagnostics have not yet been authored. Source limitations and encountered PYQ ambiguities are recorded in the curriculum. The eight other curriculum files remain empty placeholders.

No practice tests have been generated yet; they are created on demand after chapter content exists.
